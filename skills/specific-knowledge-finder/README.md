# Specific Knowledge Finder

**帮助找到你的"专长"——那些无法被教授、无法被外包、对你像玩耍对别人像工作的独特能力。**

## 这是什么？

纳瓦尔说：

> "在'成为自己'这件事上，没人能比得过你。"

但很多人不知道自己的专长是什么。

这个 skill 帮你找到它。

## 安装

```bash
cp -r specific-knowledge-finder ~/.claude/skills/
```

## 使用方法

在 Claude Code 中输入：

```
/specific-knowledge-finder
```

然后描述你的困惑，比如：

> "我工作五年了，做运营。感觉自己什么都会一点——能写文案、能做活动、能分析数据，但跳槽时发现自己没有任何不可替代的技能。"

## 什么是"专长"？

纳瓦尔定义的专长有四个特征：

| 特征 | 说明 |
|-----|------|
| **无法被教授** | 学校教不了，培训班学不会 |
| **无法被外包** | 必须你亲自做，别人代劳不了 |
| **对你像玩耍** | 你乐此不疲，别人觉得是苦差事 |
| **对你很自然** | 你不费力就能做好 |

## 一个完整的使用案例

**用户输入：**
> 我工作五年了，做运营。感觉自己什么都会一点，但跳槽时发现没有核心竞争力。

**引导对话：**
> 1. 这五年里，有什么工作是你主动想多做一点的？
> 2. 同事最常向你请教什么问题？
> 3. 有什么任务你完成得比别人快？

**用户回答：**
> 1. 我喜欢研究用户为什么流失，会主动去访谈用户
> 2. 同事经常问我"这个活动怎么设计用户才愿意参与"
> 3. 写用户调研报告比别人快很多

**输出：**
> ## 专长发现报告
>
> ### 你的核心专长
> **专长名称**：用户洞察与共情分析
>
> ### 为什么这是专长？
> - 无法被教授：共情力来自天性+长期积累
> - 无法被外包：需要你亲自访谈、感受用户情绪
> - 对你像玩耍：研究用户对你来说是探索
>
> ### 可产品化方向
> 1. 用户研究服务：为初创公司做用户调研
> 2. 知识产品：开发"用户洞察方法论"课程
> 3. 咨询顾问：帮助企业优化用户体验
