# System Trap Detector

**识别《系统之美》中的 8 大系统陷阱，分析根本原因并提供破解策略。**

## 这是什么？

你有没有遇到过这样的问题：

- 公司每年降本增效，但成本没降反升
- 问题反复出现，每次"解决"后没多久又回到原点
- 越努力越糟糕，投入越多效果越差

这可能不是"努力不够"，而是掉进了**系统陷阱**。

这个 skill 帮你识别陷阱类型，找到破解策略。

## 安装

```bash
cp -r system-trap-detector ~/.claude/skills/
```

## 使用方法

在 Claude Code 中输入：

```
/system-trap-detector
```

然后描述你遇到的问题，比如：

> "我们公司每年都在降本增效，砍预算、裁人员，但成本没降反升，问题更多了。业务部门抱怨支持部门效率低，支持部门说业务需求太多，财务说大家都乱花钱。"

## 8 大系统陷阱速查

| 陷阱 | 典型症状 | 破解方向 |
|-----|---------|---------|
| 政策阻力 | 政策越推越多，效果越来越差 | 设立更大的总体目标 |
| 公地悲剧 | 公共资源被过度使用 | 私有化/教育/规则 |
| 目标侵蚀 | 标准/绩效逐年下滑 | 保持绝对标准 |
| 转移负担 | 越来越依赖外部"救火" | 投资根本解 |
| 竞争升级 | 双方投入越来越大，收益越来越小 | 单方面退让/谈判共赢 |
| 竞争排斥 | 弱者被淘汰，强者垄断 | 引入调节机制 |
| 富者愈富 | 资源向头部集中 | 再分配/扶持弱者 |
| 规避规则 | 形式上合规，实质上违背 | 重新设计规则 |

## 一个完整的使用案例

**用户输入：**
> 我们公司每年都在降本增效，砍预算、裁人员、缩减开支，但成本没降反升...

**输出：**
> ## 陷阱诊断报告
>
> ### 识别结果
> **陷阱类型**：政策阻力
> **匹配度**：高
>
> ### 问题分析
> **根本原因**：各部门目标不一致。财务要降成本、业务要增长、支持要稳定，各方力量互相抵消。
>
> ### 破解策略
> **短期**：召开跨部门会议，识别共同目标（如"客户满意度"）
> **中期**：建立跨部门KPI，让各方利益对齐
> **长期**：调整组织架构，减少部门墙
