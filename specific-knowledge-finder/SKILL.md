# Specific Knowledge Finder（专长发现器）

## Overview

这个skill帮助您找到纳瓦尔所说的"专长"（Specific Knowledge）——您独特的、无法被培训获得的技能组合。

**核心价值：** 在"成为自己"这件事上，没人能比得过你。找到专长，才能避免同质化竞争，建立真正的护城河。

## When to Use

**触发场景：**
- 感觉自己什么都会一点，但没有不可替代的技能
- 工作多年却不知道自己的核心竞争力是什么
- 想把自己产品化，但不知道从哪个能力入手
- 同质化竞争严重，想找到自己的独特定位

---

## 核心概念

### 什么是"专长"？

纳瓦尔定义的专长有四个特征：

| 特征 | 说明 | 反例 |
|-----|------|-----|
| **无法被教授** | 学校教不了，培训班学不会 | 会计、Excel操作 |
| **无法被外包** | 必须你亲自做，别人代劳不了 | 数据录入、客服回复 |
| **对你像玩耍** | 你乐此不疲，别人觉得是苦差事 | 没有任何事让你乐此不疲 |
| **对你很自然** | 你不费力就能做好，觉得"这不是很简单吗" | 需要咬牙坚持才能完成 |

### 专长来自哪里？

专长 = 天赋 × 好奇心 × 经历

- **天赋**：你天生敏感、不费力就能做好的事
- **好奇心**：你会主动去探索、不需要外部奖励的领域
- **经历**：你独特的人生路径所积累的知识组合

**关键洞察：** 专长不是"选择"出来的，而是"发现"出来的。它已经存在于你的成长轨迹中，只是你可能没意识到。

## Workflow

### Step 1: 回溯成长轨迹

引导用户回答以下问题，收集专长的线索：

**童年线索（6-15岁）**
1. 小时候没人督促也会主动做的事是什么？
2. 什么东西能让你废寝忘食？
3. 大人们经常夸你什么？（不是夸"乖"，而是夸某种能力）
4. 有什么事你觉得很简单，但同龄人觉得很难？

**青年线索（16-25岁）**
1. 你自学过什么技能？不是为考试，纯粹是因为感兴趣
2. 有什么事你比身边大多数人做得好，却觉得"这不是很正常吗"
3. 你被什么类型的书籍/内容自然吸引？
4. 有什么活动对你来说是"休息"，对别人来说是"工作"？

**职业线索（工作后）**
1. 工作中哪些任务你完成得比别人快/好？
2. 同事最常向你请教什么问题？
3. 有什么工作你会主动多做一些，不是因为KPI？
4. 你在什么场景下会进入"心流"状态？

### Step 2: 识别专长候选

从用户的回答中提取模式，识别潜在的专长领域：

**专长类型速查表**

| 类型 | 典型表现 | 可产品化方向 |
|-----|---------|-------------|
| **连接型** | 天生认识很多人，善于搭建关系网 | 社群运营、资源对接平台 |
| **解释型** | 能把复杂概念讲得通俗易懂 | 知识付费、培训、内容创作 |
| **构建型** | 喜欢动手做东西，从0到1搭建 | 开发工具、SaaS产品 |
| **洞察型** | 能看到别人看不到的模式和趋势 | 咨询、投资、战略顾问 |
| **创造型** | 总是有新想法，不按常理出牌 | 创意设计、内容创作 |
| **执行型** | 说干就干，执行力超强 | 项目管理、运营优化 |
| **共情型** | 能快速理解他人情绪和需求 | 心理咨询、用户研究、HR |
| **分析型** | 擅长拆解问题、找规律 | 数据分析、研究、尽调 |

### Step 3: 交叉验证

用三个维度验证候选专长是否成立：

```
验证问题：
1. 【热爱】如果没有报酬，你愿意继续做这件事吗？
2. 【擅长】做这件事时，你是否比大多数人更轻松/更出色？
3. 【被需要】是否有人愿意为此付费/寻找你的帮助？

三个都是YES → 这就是你的专长
两个YES → 可以培养的方向
一个YES → 需要继续探索
零个YES → 不是你的专长
```

### Step 4: 输出专长报告

```
## 专长发现报告

### 你的核心专长
**专长名称**：{一句话描述}
**具体表现**：
- {具体场景1}
- {具体场景2}
- {具体场景3}

### 专长构成
- 天赋：{你天生擅长什么}
- 好奇心：{你自然被什么吸引}
- 经历：{你独特的人生路径}

### 为什么这是专长？
- 无法被教授：{为什么学校教不了}
- 无法被外包：{为什么必须你亲自做}
- 对你像玩耍：{为什么你乐此不疲}
- 独特组合：{你的知识组合有什么独特性}

### 可产品化方向
1. {方向1}：{具体做法}
2. {方向2}：{具体做法}
3. {方向3}：{具体做法}

### 下一步行动
{短期内可以采取的具体行动}
```

## Example Session

**用户输入**：
> 我工作五年了，做运营。感觉自己什么都会一点——能写文案、能做活动、能分析数据，但跳槽时发现自己没有任何不可替代的技能。面试官问"你的核心竞争力是什么"，我答不上来。

**引导对话**：
> 让我问你几个问题：
> 1. 这五年里，有什么工作是你主动想多做一点的，不是因为KPI？
> 2. 同事最常向你请教什么问题？
> 3. 有什么任务你完成得比别人快？

**用户回答**：
> 1. 我喜欢研究用户为什么流失，会主动去访谈用户、翻反馈，一搞就是一天
> 2. 同事经常问我"这个活动怎么设计用户才愿意参与"，我会给他们分析用户心理
> 3. 写用户调研报告比别人快很多，别人写一天，我两小时搞定

**分析输出**：
> ## 专长发现报告
>
> ### 你的核心专长
> **专长名称**：用户洞察与共情分析
> **具体表现**：
> - 主动研究用户行为背后的动机
> - 能快速理解用户心理并给出策略建议
> - 用户调研报告写得又快又好
>
> ### 专长构成
> - 天赋：共情能力强，能快速理解他人需求
> - 好奇心：对"人为什么这样做"有天然兴趣
> - 经历：五年运营积累了大量用户接触经验
>
> ### 为什么这是专长？
> - 无法被教授：共情力来自天性+长期积累，不是培训班能教的
> - 无法被外包：需要你亲自访谈、感受用户情绪
> - 对你像玩耍：研究用户对你来说是探索，对别人可能是任务
> - 独特组合：运营经验+共情力+分析能力
>
> ### 可产品化方向
> 1. **用户研究服务**：为初创公司做用户调研和洞察报告
> 2. **知识产品**：开发"用户洞察方法论"课程
> 3. **咨询顾问**：帮助企业优化用户体验和转化率
>
> ### 下一步行动
> - 整理过去做过的用户调研案例，形成作品集
> - 在公众号/小红书输出用户洞察方法论，建立专业形象
